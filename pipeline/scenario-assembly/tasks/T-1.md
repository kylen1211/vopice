  - 保留派生常量 `OFFICIAL_SECTION = f"{IDENTITY_DEFAULT_SECTION}\n\n{VOICE_SAFETY_SECTION}"` 与 `SYSTEM_PROMPT`(默认模板 + 开启态组合快照);两者标注「兼容派生,新代码不得引用」。

  - **本轮设计变更落点**:`ScenarioTemplate` 在契约 §0.1 所列字段之外**新增可选字段 `language_section: str | None = None`**(`None` = 沿用 `prompts.LANGUAGE_SECTION`);`build_system_prompt` 第 4 段取值改为「模板值优先、否则默认常量」的同一形状(与身份段一致)。
