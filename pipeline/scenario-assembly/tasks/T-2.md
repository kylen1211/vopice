## Interfaces

**Consumes**

- T-1 产出的 `server/scenarios.py` 公开接口:`ScenarioTemplate` / `ServiceChoice` / `TEMPLATES` / `get_template()` / `template_ids()`(依赖方向 `config → scenarios`,单向)。
- `contract/cases.md` §0.3:新增/变更环境变量表、生效值优先级、`Config` 字段变更表、五步校验顺序、"模板覆盖不放松凭证必需性"。
- `contract/cases.md` §0.1 INV-2:`TEMPLATES.keys()` 与 `config._PHASE2_SCENARIOS` 不相交。
- 既有机制(复用,不重写):`_validate_provider` provider 白名单校验、条件必需 key 表、`load_config()` 一次性列全缺失项的报错形状、`__repr__` 脱敏。

**Produces**

- `server/config.py`(改):
  - `Config` 字段:**删** `scenario: str`,**加** `template: ScenarioTemplate`(M-2,零外部消费者,直接替换,无双写期);**加** `fast_llm_model: str`、`dual_brain_enabled: bool`;`slow_llm_model: str | None`(M-1,条件必需);`llm_model` 语义收窄为"网关默认模型"(注释写明,`dispatch_llm` 继续用它,模板**不得**影响它)。
  - `SCENARIO` 解析:合法值 = `template_ids()`;`_PHASE2_SCENARIOS` 成员 → **保持现状文案**的"属后续阶段,暂未开放"拒绝;其余未知值 → 现状"不是有效值"拒绝;两者都是 `ConfigError`,不得抛未捕获异常。
  - `DUAL_BRAIN_ENABLED` 解析:真值集 `{1,true,yes,on}` / 假值集 `{0,false,no,off,""}`(大小写不敏感),**默认关闭**;集合外取值 → `ConfigError`,**禁止静默当假**。
  - 生效值合并(优先级 `模板 services 覆盖 > 环境变量 > 内置默认`)写进既有中立字段 `stt_provider` / `stt_model` / `tts_provider` / `tts_voice` / `tts_model`,并新增 `fast_llm_model = 模板覆盖 or LLM_MODEL`。**`bot.py` 的 builder 不感知模板**这条既有约定不变。
  - 校验顺序严格按 §0.3 五步:① 取模板 → ② 解析开关 → ③ 计算生效 provider(越白名单即 `ConfigError`)→ ④ 按**生效** provider + 开关状态汇总必需 key 表 → ⑤ 一次性列出全部缺失/`CHANGE_ME_` 占位项。**禁止**静默回退默认模板或默认 provider;**禁止**用"字段非空"代理"资源可用"。
  - **STT provider 扩展(修订 R2,M-6)**:`_STT_PROVIDER_WHITELIST` 加 `assemblyai`;`_STT_PROVIDER_REQUIRED_ENV` 加 `{"assemblyai": {"ASSEMBLYAI_API_KEY": "stt_api_key"}}`(落既有中立字段 `stt_api_key`,builder 不感知厂商)。未选中 `assemblyai` 的用户**不必**配该 key(既有条件必需机制原样生效);默认模板行为零变化。
  - **INV-2 import 期自检**落本文件(`config` 已 import `scenarios`,方向不成环):`TEMPLATES.keys()` 与 `_PHASE2_SCENARIOS` 相交即 import 期报错。
- `server/.env.example`(改):新增 `DUAL_BRAIN_ENABLED`(默认 false,含真/假值集说明);`SLOW_LLM_MODEL` 标注为"仅开关开启时必需";**新增 `ASSEMBLYAI_API_KEY=CHANGE_ME_assemblyai_api_key`**(占位符,纪律 9;注释写明「仅当生效 STT provider = assemblyai 时必需,`english_tutor` 模板默认选中它」);`SCENARIO` 注释列出合法模板 id 并写明**优先级**(模板声明的 provider 会覆盖 `STT_PROVIDER`/`TTS_PROVIDER` 等环境变量,design R-9)。
