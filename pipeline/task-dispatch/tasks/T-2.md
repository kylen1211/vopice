   ```
   cd /home/ky/git/voice-agent/server && python3 -c "import task_dispatch_contract as m; print(sorted(n for n in dir(m) if not n.startswith('_')))"
   ```
   可证伪期望:在**不带** `NLTK_DISABLE_IMPORT_SECURITY=1`、**不加载** `.env`、不激活 `.venv` 的裸解释器下退出码 0 并打印出常量名列表。若它依赖任何环境变量或运行时配置,这条会当场失败。
2. **D-003 守法②**(账本 2026-08-08 s2a 裁决⑤):本模块不得在模块顶层读环境变量或调 `load_config()`。可执行:
   ```
   cd /home/ky/git/voice-agent/server && python3 -c "
   import ast
   tree = ast.parse(open('task_dispatch_contract.py').read())
   bad = []
   for node in tree.body:
       if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef, ast.Import, ast.ImportFrom)):
           continue
       for sub in ast.walk(node):
           if isinstance(sub, ast.Call):
               nm = getattr(sub.func, 'id', None) or getattr(sub.func, 'attr', None)
               if nm in ('load_config', 'load_dotenv', 'getenv'):
                   bad.append((sub.lineno, nm))
   print('TOPLEVEL_ENV_CALLS=', bad)
   "
   ```
   可证伪期望:输出恰为 `TOPLEVEL_ENV_CALLS= []`。外加 `grep -n "os.environ" server/task_dispatch_contract.py` 零命中。
3. **D-003 守法①**:新增逻辑落本模块,不写进 `server/bot.py`。判定:本卡 `git -C /home/ky/git/voice-agent diff --stat` 只出现 `server/task_dispatch_contract.py` 一个文件。
